<p>Five sets of rollable tables and supporting drag-and-drop items that allow a player to quickly randomize and build a character. Many tables in this module are dependent on the Stormlight Handbook and Mistborn Handbook premium modules for drag-and-drop content.</p>
<p>In the current version, the resulting character will only lack the four assignable skill points, optional expertises, purpose, and obstacle to qualify as a complete Level One character for the Stormlight or Mistborn settings.</p>

This module is a Foundry implementation of a set of tables made to be used with a regular Cosmere RPG polyhedral dice set.
